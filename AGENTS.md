# PrivateSEO Аналитика — вход для агента

Публичный Telegram-бот Яндекс Метрики, Python 3.11+, SQLite, стандартные HTTP-клиенты. Репозиторий **публичный**: никаких токенов, баз, Telegram ID, реальных отчётов и пользовательских данных в Git, тестах или документации.

Перед работой прочитать [README.md](README.md), [docs/operations.md](docs/operations.md), [PRIVACY.md](PRIVACY.md). Исправления аудита и ограничения: [docs/release-0.2.0.md](docs/release-0.2.0.md).

Проверки: `.venv/bin/ruff check .`, `.venv/bin/ruff format --check .`, `.venv/bin/pytest -q`. Код и документация — один коммит; по завершении коммит и push. Не запускать второй `getUpdates` против боевого бота: это забирает сообщения у основного процесса. Тестировать изолированно; реальные тестовые отчёты — только владельцу, без рассылки пользователям. Перед миграцией сделать согласованный SQLite backup; не копировать открытый WAL-файл обычным `cp`.

Авторизация запрашивает исключительно `metrika:read`; расширять права нельзя. Все отмеченные пользователем цели входят в итог, эвристика названия применяется только к рекомендации. Данные всех запросов — без роботов и в часовом поясе отчёта. Не превращать отсутствие строки неполной выгрузки в нулевой трафик. Каждая клавиатура настройки привязана к поколению подключения; каждый отчёт — к исходному периоду и выбранным целям. Перед отправкой и завершением OAuth повторно проверять актуальность подключения.
